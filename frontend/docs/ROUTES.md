# Routes

Public routes live under `frontend/app/`:
- `/` home
- `/events` event listing
- `/register/[eventSlug]` registration + payments
- `/support` support/donations

Admin routes:
- `/admin/login`
- `/admin/dashboard`
- `/admin/cms/*` (posts/pages/media)
- `/admin/events/*` (including results import and bib tools)
- `/admin/sponsors`
- `/admin/finance`
- `/admin/reconciliation`
