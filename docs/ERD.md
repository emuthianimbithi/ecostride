# ERD

This file captures the core entity relationships for EcoStride.

Key entities
- Identity/RBAC: users, roles, permissions, user_roles, role_permissions
- CMS: pages, posts, media, waivers
- Events: events, categories, form_fields
- Registrations: registrations, consent_records
- Payments/Receipts: payments, payment_events, receipts
- Bibs/Check-in: bib_assignments, checkins
- Results: result_imports, results
- Finance: bank_imports, reconciliation_matches
- Sponsors: sponsor_tiers, sponsors, sponsor_placements, sponsor_views
- Volunteers: volunteers, volunteer_assignments, volunteer_attendance
- Shop: products, orders, order_items

Add a diagram export (e.g. dbdiagram.io) when the schema is finalized.
